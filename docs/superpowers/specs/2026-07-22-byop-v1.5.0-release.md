# v1.5.0 release notes

## Highlights

- **`--export-config`** — Print the byop-managed slice of each target's
  settings as JSON and exit. No writes, no provider prompts. Combine with
  `--target` (restrict to one target) and `--export-provider` (filter to a
  single named provider). Useful for diffing between runs, copying a fragment
  into another tool, or confirming what byop actually wrote.

- **Fix**: Stray ESC bytes (`\x1b`) leaked into interactive prompts. Rich's
  `Prompt.ask` echoes ESC as `^[` rather than ignoring it; hitting Escape a few
  times in a row during the JSON-paste prompt used to leave the buffer full of
  caret-notation garbage. Now stripped at the prompt layer so the wizard sees
  a clean value.

## Usage

```bash
byop --export-config
byop --export-config --target zed
byop --export-config --export-provider HyberOrbit
```

Output shape:

```json
{
  "zed": {
    "config_path": "/Users/you/.config/zed/settings.json",
    "providers": { "HyberOrbit": { "api_url": "...", "available_models": [...] } },
    "agent": { "default_model": { ... } },
    "edit_predictions": { ... }
  },
  "py": { "config_path": "...", "providers": { ... } }
}
```

## Implementation

- `Target.export_config()` added to the `Target` protocol in
  `byop/core/targets/base.py`. Every target (zed, py, omp, opencode, claude)
  implements it.
- `_strip_escape_chars()` added to `byop/core/prompt.py`; applied to every
  input-reading path (`ask`, `ask_secret`, `ask_int`, `confirm`, `choose`,
  `choose_action`).
- CLI wiring in `byop/cli.py::_run_export`, triggered before provider
  resolution so the wizard never starts when `--export-config` is set.

## Tests

- `tests/test_prompt.py` — covers `_strip_escape_chars` (ESC bytes, CSI
  sequences, no-op on clean text).
- `tests/test_export_config.py` — per-target shape, missing-file safety, CLI
  glue with `--export-provider` filtering.
